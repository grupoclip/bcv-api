Integrations

The same official Banco Central de Venezuela rates, wherever you need them: in the browser, in your code, in your ERP or in your AI assistant.

Everything comes from the same data: the rate the BCV publishes, with its value date. Everything is free, read-only and needs no API key. The data is published under CC BY 4.0: if you show it, credit the source.

For people

Website

bcv.today

The current USD, EUR, CNY, TRY and RUB rates with a calculator, for anyone who just wants to know what the BCV dollar is worth today.

See today's rates →

History

The daily chart and table for each currency, to compare dates, see the change over a period or look up the rate on a given day.

For developers

JSON API

HTTP · JSON · no key

Static JSON files with the current rate, the daily history and the data status, for any language that can make an HTTP request.

curl -s {{ site.url }}{{ site.baseurl }}/api/v1/rate.json

API reference → OpenAPI Status

Python library bcv

PyPI · Python 3.9+

A zero-dependency client with caching, Decimal math, weekend carry-forward and a bcv command, for Python scripts, notebooks and backends.

pip install bcv

View on PyPI → Guide Source code

JavaScript library bcv-today

npm · Node 18+, Deno, Bun, browser

A zero-dependency TypeScript client with caching, exact decimal math, weekend carry-forward, a bcv-today command and a local MCP server, for backends, frontends and Workers.

npm install bcv-today

View on npm → Guide Source code

Odoo module l10n_ve_bcv_rate

Odoo 16–20 · free

Updates every company's currency rates daily in Odoo Community and Enterprise (Odoo.sh or on-premise; not Odoo Online), for anyone invoicing in bolivars or foreign currency.

Copy it into your addons path, then Apps → search “BCV” → Activate.

View on Odoo Apps → Source code Guide

For AI agents

MCP server

Streamable HTTP · no auth

Five tools for rates, dates, history and conversion, for Claude, ChatGPT, Cursor, VS Code and any Model Context Protocol client.

claude mcp add --transport http bcv-today https://mcp.bcv.today/mcp

How to connect it → Server card

A2A agent

A2A 1.0 and 0.3 · no auth

An Agent2Agent agent that answers in Spanish or English about rates, dates and conversions, so other agents can ask it without learning the API.

curl -s https://mcp.bcv.today/a2a -H 'Content-Type: application/json' -H 'A2A-Version: 1.0' -d '{"jsonrpc":"2.0","id":1,"method":"SendMessage","params":{"message":{"role":"ROLE_USER","messageId":"1","parts":[{"text":"convert 100 USD to VES"}]}}}'

How to use it → Agent card

WebMCP in the browser

navigator.modelContext

In browsers with WebMCP, every bcv.today page registers five read-only tools (get_latest_bcv_rates, get_bcv_rate_by_date, get_bcv_rate_history, get_bcv_api_status and open_bcv_api_docs) for the agent browsing with you.

See the tools → WebMCP specification

Pages as Markdown

Accept: text/markdown

Every page on the site is also served as clean Markdown, for agents and readers that don't need the HTML: ask for it with that header or append index.md to the URL.

curl -s -H 'Accept: text/markdown' {{ site.url }}{{ site.baseurl }}/en/
