Integraciones

Las mismas tasas oficiales del Banco Central de Venezuela, donde las necesites: en el navegador, en tu código, en tu ERP o en tu asistente de IA.

Todo sale de los mismos datos: la tasa que publica el BCV, con su fecha valor. Todo es gratuito, de solo lectura y sin claves de acceso. Los datos se publican bajo CC BY 4.0: si los muestras, cita la fuente.

Para personas

Sitio web

bcv.today

Las tasas vigentes de USD, EUR, CNY, TRY y RUB con una calculadora, para quien solo quiere saber cuánto vale hoy el dólar BCV.

Ver las tasas de hoy →

Histórico

desde 2021

El gráfico y la tabla diaria de cada moneda, para comparar fechas, ver la variación de un período o buscar la tasa de un día.

Ver el histórico →

Para desarrolladores

API JSON

HTTP · JSON · sin clave

Archivos JSON estáticos con la tasa vigente, el histórico diario y el estado de los datos, para cualquier lenguaje que pueda hacer una petición HTTP.

curl -s {{ site.url }}{{ site.baseurl }}/api/v1/rate.json

Documentación de la API → OpenAPI Estado

Librería Python bcv

PyPI · Python 3.9+

Cliente sin dependencias con caché, Decimal, arrastre de fines de semana y el comando bcv, para scripts, notebooks y backends en Python.

pip install bcv

Ver en PyPI → Guía Código fuente

Librería JavaScript bcv-today

npm · Node 18+, Deno, Bun, navegador

Cliente TypeScript sin dependencias con caché, aritmética decimal exacta, arrastre de fines de semana, el comando bcv-today y un servidor MCP local, para backends, frontends y Workers.

npm install bcv-today

Ver en npm → Guía Código fuente

Módulo de Odoo l10n_ve_bcv_rate

Odoo 16–20 · gratis

Actualiza a diario las tasas de cada compañía en Odoo Community y Enterprise (Odoo.sh o servidor propio; no Odoo Online), para quien factura en bolívares o en divisas.

Cópialo en tu ruta de addons y luego Apps → buscar «BCV» → Activar.

Ver en Odoo Apps → Código fuente Guía

Para agentes de IA

Servidor MCP

Streamable HTTP · sin auth

Cinco herramientas de tasas, fechas, histórico y conversión para Claude, ChatGPT, Cursor, VS Code y cualquier cliente Model Context Protocol.

claude mcp add --transport http bcv-today https://mcp.bcv.today/mcp

Cómo conectarlo → Server card

Agente A2A

A2A 1.0 y 0.3 · sin auth

Un agente Agent2Agent que responde en español o inglés sobre tasas, fechas y conversiones, para que otros agentes le pregunten sin conocer la API.

curl -s https://mcp.bcv.today/a2a -H 'Content-Type: application/json' -H 'A2A-Version: 1.0' -d '{"jsonrpc":"2.0","id":1,"method":"SendMessage","params":{"message":{"role":"ROLE_USER","messageId":"1","parts":[{"text":"convertir 100 USD a VES"}]}}}'

Cómo usarlo → Agent card

WebMCP en el navegador

navigator.modelContext

En navegadores con WebMCP, cada página de bcv.today registra cinco herramientas de solo lectura (get_latest_bcv_rates, get_bcv_rate_by_date, get_bcv_rate_history, get_bcv_api_status y open_bcv_api_docs) para el agente que navega contigo.

Ver las herramientas → Especificación WebMCP

llms.txt

texto plano

Un índice corto del sitio y de la API para modelos de lenguaje, con una versión completa en un solo archivo y un catálogo de recursos para agentes.

Abrir llms.txt → llms-full.txt AI catalog
