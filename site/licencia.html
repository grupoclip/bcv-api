Código

El código fuente (el scraper que lee la página del Banco Central de Venezuela, este sitio web y los scripts del repositorio) se publica bajo la licencia Apache 2.0. Puedes usarlo, modificarlo y distribuirlo, también dentro de productos comerciales, siempre que conserves el texto de la licencia y los avisos de copyright e indiques los archivos que cambiaste. La licencia incluye además una concesión de patentes.

Datos y API

Los archivos JSON de la API (/api/v1/), el histórico diario y los textos de este sitio se publican bajo la licencia Creative Commons Atribución 4.0 Internacional (CC BY 4.0).

  • Puedes copiarlos, redistribuirlos, transformarlos y construir sobre ellos.
  • Puedes hacerlo con cualquier fin, incluido el comercial, sin pedir permiso ni pagar.
  • La única condición es dar crédito: citar la fuente, enlazar a la licencia e indicar si hiciste cambios.

El resumen anterior no sustituye al texto legal de la licencia.

Cómo dar crédito

Basta con una línea visible cerca de donde muestras las tasas:

Fuente: Banco Central de Venezuela, vía BCV Today (https://bcv.today)

En una página web, con enlaces:

Fuente: Banco Central de Venezuela, vía <a href="https://bcv.today">BCV Today</a>
(<a href="https://creativecommons.org/licenses/by/4.0/deed.es">CC BY 4.0</a>)

En Markdown, por ejemplo en un README:

Fuente: Banco Central de Venezuela, vía [BCV Today](https://bcv.today)
([CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.es))

Según cómo uses los datos:

  • En una app o sitio que muestra las tasas: un crédito visible o un enlace a bcv.today junto a las cifras, o en la pantalla de información o de créditos de la app.
  • En un servicio sin interfaz (un backend, un bot o una integración que consume la API): el crédito en la documentación o en el README del proyecto.
  • Si modificas los datos (por ejemplo, redondeos o tasas calculadas a partir de estas): indícalo, por ejemplo “calculado a partir de datos de BCV Today”.

Las tasas del BCV

Las tasas de cambio en sí son datos públicos oficiales que publica el Banco Central de Venezuela. BCV Today no reclama derechos sobre esas cifras. La licencia CC BY 4.0 cubre lo que aporta este proyecto: la recopilación, el formato JSON, el histórico diario y los textos.

Nombre y logo

El nombre “BCV Today” y su logo no están cubiertos por ninguna de las dos licencias. Puedes mencionarlos para dar crédito o referirte al proyecto, pero no usarlos para presentar una copia o un fork como el proyecto oficial ni para sugerir que BCV Today respalda tu producto. Si publicas un fork, usa otro nombre y otro logo.
