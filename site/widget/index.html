Atributos

Todos se pueden cambiar en cualquier momento y el widget se actualiza.

AtributoValoresPor defecto
currencyUSD, EUR, CNY, TRY, RUBUSD
variantcard (tarjeta), line (en línea, dentro de una frase), converter (monto a bolívares)card
langes, enEl lang más cercano en la página (en* es inglés); si no hay, es
themeauto (sigue prefers-color-scheme), light, darkauto
amountMonto inicial del convertidor, un número simple como 100 o 1234.51
hide-sourceBooleano: oculta el enlace "Fuente: BCV Today"Visible
apiOrigen de los datos, para pruebas o un espejohttps://bcv.today

Los números siguen el idioma: en español, el formato venezolano (916,6477, 1.007,3867); en inglés, el de EE. UU. (916.6477, 1,007.3867). Las tasas llevan 4 decimales y los montos convertidos, 2. El convertidor acepta montos como 1.234,5 o 1234.5.

Propiedades CSS

Defínelas en el elemento o en cualquier contenedor. --bcv-bg y --bcv-text reemplazan el valor claro y el oscuro a la vez, así que elige un par con buen contraste o defínelas por tema.

PropiedadPor defecto (claro / oscuro)
--bcv-accent#f2b33d, el dorado del logo de BCV Today (logo y borde del campo con foco)
--bcv-bg#fdfbf7 / #1c1a18
--bcv-text#1f1b16 / #efe9de
--bcv-radius12px (tarjeta y convertidor); la variante en línea es totalmente redondeada si no la defines
--bcv-fontLa fuente del sistema (la variante en línea hereda la del texto); los números siempre van en monoespaciada

Partes (::part())

El widget usa Shadow DOM: tu CSS no entra y el suyo no sale. Para ajustar piezas concretas usa bcv-rate::part(nombre) con estas partes: container, label, value, change, date, note (aviso de dato guardado), source, mark, status (textos de carga y error) y, en el convertidor, input y result. 

bcv-rate {
  --bcv-radius: 4px;
  --bcv-font: "Inter", sans-serif;
}
bcv-rate::part(value) {
  font-weight: 700;
}

Eventos

El widget no emite eventos propios. En el convertidor, el campo de monto es un <input> normal dentro del Shadow DOM.

Lo que debes saber

  • Sin cookies ni rastreo. Solo guarda la última tasa válida en el localStorage del navegador, para mostrarla si la API no responde (con un aviso de "Dato guardado").
  • Solo lee datos públicos. Pide {{ base }}/api/v1/rate.json y los archivos diarios del histórico para calcular la variación. Todos los widgets de la página comparten las mismas peticiones y se actualizan cada 30 minutos mientras la página está visible.
  • Funciona con una CSP estricta. Arma el contenido con APIs del DOM, nunca interpretando HTML, así que basta con script-src https://bcv.today y connect-src https://bcv.today; también es compatible con Trusted Types.
  • Liviano. Unos 5 KB comprimido con gzip, sin dependencias.
  • Accesible. Texto real (no imágenes de números), un nombre accesible como "Tasa BCV: Dólar (USD)", la dirección de la variación en palabras para lectores de pantalla y contraste de al menos 4,5:1 en ambos temas.
